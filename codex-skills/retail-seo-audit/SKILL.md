# Retail Seo Audit

Build a table with URL, page role, evidence, proposed change and verification. Walk from the homepage through the menu to a category and product. A search-results URL, a published collection URL, and a collection listed in the sitemap are three distinct states. Check each independently.
For each product and collection, draft a unique title and description that match the visible offer. Map a primary topic to one page and distinguish candidate queries from measured search demand. Preserve existing handles unless a migration and redirects are explicitly requested.
Example: replace a menu link to `/search?q=speaker` with a draft collection link, then verify the target is public and check the collection sitemap separately after an approved publish.

Save findings and proposed edits in a local draft. Include current and proposed values, evidence, and the checks to run after release. Live changes and publishing require the user’s approval after reviewing the draft.
